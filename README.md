# CashBrain — навигатор по мерам поддержки для ИП

Чат-бот в мессенджере MAX, который помогает индивидуальным предпринимателям:
1. Подобрать подходящие меры поддержки (субсидии, гранты, кредиты).
2. Спрогнозировать доход от привлечённого финансирования.
3. Распределить бюджет по статьям расходов.


## 🧠 FSM: как бот ведёт диалог
FSM (Finite State Machine — машина состояний) — это механизм, который позволяет боту помнить, на каком шаге диалога находится пользователь, и знать, что спрашивать дальше.
Без FSM бот не смог бы отличить ответ на вопрос «В каком вы регионе?» от ответа на вопрос «Какая у вас выручка?».

### Состояния профиля
В `bot/handlers/profile.py` определены следующие состояния:

```python
class ProfileForm(State):
    waiting_for_industry = State()        # Ждём отрасль
    waiting_for_region = State()          # Ждём регион
    waiting_for_capital = State()         # Ждём капитал
    waiting_for_target_revenue = State()  # Ждём цель по выручке
    finished = State()                    # Сбор завершён
```

## Сценарий работы
1. Пользователь пишет /start в MAX.
2. Бот собирает профиль ИП:
  Отрасль (например, «кофейня»).
  Регион (например, «Нижегородская область»).
  Начальный капитал.
  Цель по выручке — сколько хочет зарабатывать.
3. Бот подбирает подходящие программы (matcher.py).
4. Бот показывает список программ (федеральные + региональные).
5. Пользователь нажимает «Рассчитать доход».
6. Бот считает 3 сценария (calculator.py):
  🟢 Оптимистичный
  🟡 Реалистичный
  🔴 Пессимистичный
7. Пользователь нажимает «Распределить бюджет».
8. Бот предлагает 3 сценария распределения (budget.py):
  🟢 Осторожный
  🟡 Сбалансированный
  🔴 Агрессивный
