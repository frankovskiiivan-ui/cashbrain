# CashBrain — навигатор по мерам поддержки для ИП

Чат-бот в мессенджере MAX, который помогает индивидуальным предпринимателям:
1. Подобрать подходящие меры поддержки (субсидии, гранты, кредиты).
2. Спрогнозировать доход от привлечённого финансирования.
3. Распределить бюджет по статьям расходов.


## Архитектура 

cashbrain/
├── bot/                    # 🤖 Слой интерфейса (MAX)
│   ├── main.py             # Точка входа
│   ├── keyboards.py        # Inline-клавиатуры
│   └── handlers/           # Обработчики сообщений (FSM)
│       ├── start.py        # /start
│       ├── profile.py      # Сбор профиля ИП (4 шага)
│       ├── programs.py     # Вывод и выбор программ
│       └── budget.py       # Распределение бюджета
│
├── core/                   # 🧠 Бизнес-логика (чистый Python)
│   ├── matcher.py          # Подбор программ по профилю
│   ├── calculator.py       # Расчёт дохода (3 сценария)
│   └── budget.py           # Логика распределения бюджета
│
├── data/                   # 🗄️ Слой данных
│   ├── db.py               # Подключение к SQLite
│   ├── models.py           # SQLAlchemy модели
│   ├── loader.py           # Загрузчик JSON → SQLite
│   └── sources/
│       └── programs.json   # База мер поддержки (15 программ)
│
├── utils/                  # 🔧 Утилиты
│   └── validators.py       # Проверка ввода
│
├── tests/                  # 🧪 Тесты (pytest, 33 теста)
└── simulate.py             # Симулятор диалога без MAX
